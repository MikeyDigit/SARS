# Responsible AI Use Statement

This project demonstrates the use of AI as a support tool while still maintaining student understanding and ownership of the code.

## How AI Was Used

AI was used in three main ways:

1. **Planning and explanation**  
   AI helped break the program into smaller parts, such as the student structure, ranking logic, scoring categories, and menu system.

2. **Debugging support**  
   AI was used to help understand compiler errors, structure issues, and logic problems. The final code still had to be reviewed, tested, and understood by the developers.

3. **AI-style scoring support**  
   The extracurricular scoring system uses keyword-based logic to evaluate student activities differently depending on the student's category. This demonstrates how AI-style classification can support a ranking system while keeping the final logic inside C++.

## What AI Did Not Replace

AI did not replace the need to understand the program. The project still required knowledge of:

- how classes interact
- how inheritance works
- how vectors store students and activities
- how sorting ranks students
- how input validation protects the program
- how final scores are calculated
- how AI-generated help must be reviewed before use

## Academic Integrity Statement

AI was used as a tool for guidance, debugging, and explanation, not as a replacement for learning. The submitted project demonstrates understanding of C++ concepts through the structure of the system, the use of object-oriented programming, and the ability to explain how the code works.

A major rule followed during the project was:

> AI can help write or debug code, but I must be able to explain what the code does before submitting it.

That is the difference between using AI properly and blindly copying code.
